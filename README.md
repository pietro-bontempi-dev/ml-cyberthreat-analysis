# ml-cyberthreat-analysis
Este projeto analisa tendências de ataques cibernéticos e utiliza Machine Learning para identificar padrões e classificar ameaças como ransomware, phishing, DDoS, trojans e outras. O objetivo é avaliar o desempenho do modelo e seu potencial na detecção de comportamentos maliciosos e prevenção de incidentes de segurança.
